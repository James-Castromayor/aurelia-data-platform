# Aurelia Enterprise Cloud Data & Analytics Platform

Aurelia is a fictional professional-services company used to demonstrate an end-to-end enterprise Cloud Data & Analytics Engineering platform.

## Project Goal

Design and implement a maintainable data ecosystem integrating CRM, operational, financial, automation, analytics, and AI capabilities.

## Core Technology Stack

- SQL
- Python
- Microsoft Azure
- Snowflake
- dbt
- Power BI
- PostgreSQL
- REST APIs
- n8n
- Git / GitHub

## Supporting Technologies

- ASP.NET Core
- React
- Docker
- PySpark
- Microsoft Fabric
- RAG / AI Agents

## High-Level Data Flow

HubSpot CRM / Operations / Finance / Files / APIs  
↓  
Python + n8n  
↓  
Azure Blob Storage  
↓  
Snowflake  
↓  
dbt  
↓  
Dimensional Data Marts  
↓  
Power BI / APIs / AI

## Project Status

Current phase: Phase 0 — Foundation

## Portfolio Principles

- Synthetic data only
- No employer systems or proprietary information
- Security and cost management by design
- Incremental Git history
- Documentation-first engineering
- Cloud Data Engineering remains the primary focus
