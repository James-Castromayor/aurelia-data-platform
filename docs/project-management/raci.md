# Aurelia Project RACI Matrix

## Purpose

This document defines high-level responsibilities for delivery of the Aurelia Enterprise Cloud Data & Analytics Platform.

## RACI Definitions

* **R — Responsible:** Performs the work.
* **A — Accountable:** Ultimately owns the outcome.
* **C — Consulted:** Provides required input.
* **I — Informed:** Kept aware of progress or outcomes.

## Portfolio Delivery Note

Because Aurelia is a fictional portfolio environment, the portfolio engineer performs several technical and analytical roles that would normally be distributed across multiple team members in a production organization.

The RACI represents how responsibilities could reasonably be divided in a real enterprise implementation.
