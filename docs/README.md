# Aurelia Documentation

This directory contains the business, project, architecture, security, testing, and operational documentation for the Aurelia Enterprise Cloud Data & Analytics Platform.

## Sections

- `project-management/` — project charter, planning, RAID, RACI
- `business-analysis/` — requirements and business processes
- `architecture/` — system, integration, data, deployment, and AI architecture
- `security/` — security design and controls
- `testing/` — testing strategy and evidence
- `runbooks/` — deployment and operational procedures
